# lab-backend

## Dependencias
Recomendado usar un entorno virtual:  
 $ python -m venv venv  
 $ source venv/bin/activate  
Para instalar:  
 $ pip install -r requirements.txt

## Iniciar el servidor
Donde este la carpeta src, ejecutar:  
$ uvicorn src.main:app --reload

## Detener el servidor
Presiona CTRL + C en la terminal donde se está ejecutando el servidor

---

Luego de realizar los pasos ir a http://localhost:8000/ en el navegador.
